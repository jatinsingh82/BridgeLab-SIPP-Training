# BridgeLabz SIPP Training

This repository contains Java programming examples and exercises for the BridgeLabz SIPP Training program.

## Repository Structure

The repository is organized into day-wise folders, each containing Java files that demonstrate specific programming concepts:

### Day-wise Folders:

1. **Day1_ProgrammingElements** - Basic Java syntax and structure
   - `HelloWorld.java` - Simple Hello World program

2. **Day2_DataTypes** - Java data types and variables
   - `VariableTypes.java` - Demonstrating different data types

3. **Day3_ControlStructures** - Control flow and decision making
   - `IfElseExample.java` - If-else statements and switch cases

4. **Day4_Arrays** - Array operations and manipulation
   - `ArrayOperations.java` - Array creation, traversal, and 2D arrays

5. **Day5_Functions** - Methods and functions
   - `MethodExamples.java` - Different types of methods

6. **Day6_ObjectOrientedProgramming** - OOP concepts
   - `Student.java` - Classes, objects, constructors, and methods

7. **Day7_Strings** - String manipulation
   - `StringManipulation.java` - String operations and methods

8. **Day8_Collections** - Java Collections Framework
   - `CollectionExamples.java` - ArrayList, HashSet, and HashMap

9. **Day9_ExceptionHandling** - Exception handling
   - `ExceptionExample.java` - Try-catch blocks and custom exceptions

10. **Day10_FileHandling** - File operations
    - `FileOperations.java` - File reading, writing, and manipulation

## Git Commit Convention

All commits follow the specified convention:
- `git commit -m "[Name] Add . Commit message"`
- `git commit -m "[Name] Refactor . Commit message"`
- `git commit -m "[Name] Fix . Commit message"`

Example:
```
git commit -m "[Jatin] Add . Hello World program for Day 1"
git commit -m "[Jatin] Refactor . Improved method structure in Day 5"
git commit -m "[Jatin] Fix . Corrected array indexing in Day 4"
```

## How to Use

1. Each day folder contains Java files with examples
2. Files are named according to the problem statement
3. Each file includes proper documentation and comments
4. Follow the commit convention when making changes

## Getting Started

1. Clone the repository
2. Navigate to the desired day folder
3. Compile and run Java files
4. Follow the learning path day by day
